# fitspace-legal

Опубликованные юридические страницы Fit-Space.

**Руками здесь ничего не правят.** Источник — `Resources/privacy.md` в
основном (приватном) репозитории приложения; эта копия генерируется
скриптом `ios/FitSpace/scripts/publish-privacy.sh`. Правка здесь будет
затёрта при следующей публикации, а текст в приложении и текст по ссылке
разъедутся — чего мы и избегаем.
